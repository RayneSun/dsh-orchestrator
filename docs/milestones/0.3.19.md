# v0.3.19

## 变化

- 包名改为 @cmjt/dsh-orchestrator，客户端 ModuleLoader、typert host/remote、设置槽和 bundle 引用同步；稳定的预设及 Cordis 行 ID 保留。
- task_update 拆为 task_running/task_input_required/task_completed/task_failed，日程管理独立为 task_schedule；字段拍平并删除 report/fail。
- domain v3 隔离旧存储，删除全部历史记录迁移代码；hasActiveSchedule 收敛为 snapshot 投影。升级不兼容旧会话，需备份旧域并停用旧 Worker 定时任务。
- 删除 meow 依赖、影子记忆查询工具、共享链接逻辑；使用 @cmjt/dsh-personal-memory@latest 的原生工具。Lead 只查询，Worker 完整能力；门控通过原生接口适配实际目录，幂等重试并在推理前确认策略。
- 修复独立日程写入缺少变更广播、作答留痕被后续上报清空；input_required 不再被当成结束或投递状态。
- card 上限按 UTF-8 字节计量；日历按可见月份索引跨天日程，切月标题与选中日期一致，保留明确的零点/23:59 时间。
- 工具限制随全局注册变化刷新，晚注册的第三方写工具也保持隐藏。模型可见 DSL 与 Zod 的字段、类型和必填约束持续交叉校验。

## 文档与发布

完整 [board-api](../board-api.md) 与 [0.3.19 差异](../board-api-v0.3.19-changes.md) 随同一份构建 tgz 上传 GitHub Release；同一 tgz 同步发布私有 npm。README/AGENTS/文档索引同步。

## 已知边界

- 私有源 memory latest 当前为 0.4.5，客户端 scoped 注册缺陷已提 [issue #1](https://github.com/friendllcc/dsh-personal-memory/issues/1)。后端与门控有独立验证，本包不包含第三方产物修补。
- 日程提醒时间是 App 元数据；本插件无 remindAt 调度器。
- 日程整批预校验不等于存储跨记录事务，I/O 失败可能部分落盘。
- 原生桌面驱动与浏览器登录仍依赖用户环境，不属于本轮自动化回归覆盖。

## 验证

- host/client tsc（含 noUnusedLocals/noUnusedParameters）通过；20 个文件共 142 项 vitest 通过。
- tsdown 四入口构建与 verify:packaging 通过，包身份、客户端注册及三个 RPC descriptor 一致。
- 独立 profile 从 tgz 安装成功，自动拉取 memory latest；真实 Web 首页、记忆 API、Lead 预设创建与 snapshot RPC 通过，SQLite 核验 Lead 门控为 dream=true / inject=false / write=true。
- 默认/自定义 projectDir、原生 SQLite 路由、晚注册工具隔离、门控失败阻止推理及恢复路径均有回归测试。
- memory 0.4.5 的客户端错误在未经修补的安装中复现并单独反馈。本轮 HTTP/RPC 验证不调用模型，不等同于所有真实模型任务均已验收。
