# v0.3.21

## 变化

- Lead roster 改为实时投影当前/最近任务的需求、状态、进展或结果，并保留更新时间与日程摘要；关闭动态文本插值，避免模型内容中的 `{{...}}` 被误解析。
- Lead 派发与结果输出提示进一步收敛：同事项复用会话、不同事项新建，卡片围栏原样转发，正文不重复执行过程。
- 新增 Worker 默认模型设置：可在插件配置页选择 provider、模型与推理强度；新 Worker 优先使用，旧 Worker 仅在原模型明确失效时重选，不重建会话。
- `task_schedule` 按事件完善开始、结束和提醒时间引导，支持按事项类型合理估计结束时间与提醒提前量；`remindAt` 仍只供 App 使用。
- Task 新增可选 `requestedModel / responseModel`，Host 自动记录本轮最后一次推理的请求与上游返回模型；看板展示模型来源，路由不一致时合并显示并可悬浮查看明细。
- GenUI 固定为普通依赖 `0.15.0` 并随 bundle 启用；移除 BrowserSkill、Computer Use、QQ 邮箱及 vendored 桌面驱动，相关能力改为按需独立安装。
- 发布流程增加文档与通知门禁：发布前核对全部提交和文档，Release 正文逐项说明外部影响，发布后提供面向用户的简短通知。

## 验证

- Host / Client TypeScript 检查通过，21 个测试文件共 158 项 vitest 通过。
- tsdown 四入口构建与 packaging 校验通过；发布 tgz 只含运行所需编译产物和 bundle 文件。
- GitHub Release 与私有 Verdaccio 使用同一次 `npm pack` 产物，发布后以版本、tarball 与 shasum 核对。
- 正式 tgz 装回真实 web profile，并通过指定脚本重启 3080 做启动验证。

## 兼容边界

- 本版仅对 Task 增加可选字段；snapshot/RPC 方法、Worker 工具输入字段和 domain v3 不变，旧记录无需迁移。
- v0.3.19 起的不兼容旧会话与旧看板数据规则不变；从更老版本升级须先阅读 0.3.19 升级说明。
- 已有 Worker 不随默认模型配置立即切换；只有目录明确确认原模型失效时才重选，目录查询失败保持原状。
- `remindAt` 仍是通知元数据，本插件不会仅凭该字段触发提醒。
