# v0.3.20

## 变化

- 修复 Worker 制品在主会话只显示路径的问题：Lead 重新挂载原生 `present`，恢复 `ui:deliverable-file-references` 提示段；不因此开放 bash、定时任务等 Worker 执行工具。
- Lead 终态回复改为遵循输出规范：正文只补必要结论，`dsh-ui` 围栏原封不动，制品先通过 `present` 交付且正文不列路径。
- Worker `task_completed` 明确 `result / card / artifacts` 分工：result 不写文件路径和实现细节，card 放结构化明细，artifacts 只保留关键制品，三者不重复。
- 工具参数描述、deliveryNotice、README、AGENTS 与看板接口说明同步；snapshot、RPC 和存储 schema 相比 0.3.19 不变。
- `@cmjt/dsh-personal-memory` 依赖固定为 0.4.6，不再使用 latest；上游已修复 scoped 客户端注册问题，不再需要本机补丁，也避免旧 lockfile 继续复用 0.4.5。

## 验证

- Host / Client TypeScript 检查通过，20 个测试文件共 145 项 vitest 通过。
- tsdown 四入口构建、vendor 复制与 packaging 校验通过。
- 真实任务验收：Worker 上报 A/B/C 占比表格 card 和 `summary.md`；Lead 原样渲染卡片、通过 `present` 生成制品卡，正文没有路径或重复明细；右侧栏可正常预览 Markdown 制品。

## 兼容边界

- 本版没有新增接口字段或破坏性协议变化。
- v0.3.19 起使用的 domain v3 仍不接纳旧会话与旧看板数据；从更老版本升级须先阅读 0.3.19 升级说明。
- `remindAt` 仍是供 App 使用的通知元数据，本插件不会仅凭该字段触发提醒。
