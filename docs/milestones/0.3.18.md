## 接口与数据兼容

- **没有新增 status**。Task 仍是 queued / running / input_required / completed / failed / interrupted，Conversation 仍是 provisioning / running / idle / input_required / failed。
- snapshot、setScheduleStatus、answerTaskQuestions 三个 RPC 的名称、请求校验、响应结构不变；snapshot 的三个数组、字段和 createdAt 排序不变，下游无需适配。
- Snapshot 与 RPC 请求类型从既有 Zod schema 推导；snapshotResultSchema 移入 types.ts，remote.ts 保留重导出。时间函数与工具参数移动后保留原导出路径。
- 三种持久化记录 schema、migrateRecord 与存储 domain 版本不变，没有 schema 迁移。
- 行为修复会让停止、改单或重启中的等待任务进入已有 interrupted 状态；`input_required_answered` 是此前已有的工具返回值，不是新增持久化状态。

完整字段定义见 [看板数据接口](../board-api.md)，模块地图见 [AGENTS](../../AGENTS.md)。
